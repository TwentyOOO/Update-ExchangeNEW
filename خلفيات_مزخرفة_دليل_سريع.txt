───────────────────────────────────────────────────────────
⚡ استخدام سريع في XML:
───────────────────────────────────────────────────────────

في أي layout، أضف هذا السطر للعنصر الرئيسي:

    android:background="@drawable/bg_premium_pattern"

أو بدّل "bg_premium_pattern" بأي نمط آخر!

───────────────────────────────────────────────────────────
💻 استخدام سريع في Java:
───────────────────────────────────────────────────────────

// الطريقة السهلة:
LinearLayout layout = findViewById(R.id.main_layout);
PatternBackgroundHelper.applyPremiumPattern(layout);

// أو اختر نمط محدد:
PatternBackgroundHelper.applyPattern(layout, 
    PatternBackgroundHelper.PatternType.WHATSAPP_STYLE);

───────────────────────────────────────────────────────────
🎨 مثال كامل في onCreate():
───────────────────────────────────────────────────────────

@Override
protected void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    setContentView(R.layout.activity_main);
    
    // طريقة 1: مباشرة
    LinearLayout mainLayout = findViewById(R.id.main_layout);
    PatternBackgroundHelper.applyPremiumPattern(mainLayout);
    
    // طريقة 2: على كامل الشاشة
    View rootView = findViewById(android.R.id.content);
    PatternBackgroundHelper.applyPremiumToActivity(this, rootView);
}

🔄 تبديل الخلفيات:
───────────────────────────────────────────────────────────

لتجربة خلفية أخرى، افتح activity_main.xml وغيّر:

من:  android:background="@drawable/bg_premium_pattern"
إلى: android:background="@drawable/bg_pattern_whatsapp"

أو أي نمط آخر من القائمة أعلاه!

───────────────────────────────────────────────────────────
🎨 تخصيص الألوان (متقدم):
───────────────────────────────────────────────────────────

افتح أي ملف drawable وعدّل قيم الألوان:

<solid android:color="#143498DB"/>
                      ↑↑
                      └─ الشفافية (14 = 8%)
                         00 = شفاف تماماً
                         FF = غير شفاف

───────────────────────────────────────────────────────────
📊 معلومات الشفافية:
───────────────────────────────────────────────────────────

#00 = 0%   شفاف تماماً
#0A = 4%   شفاف جداً
#14 = 8%   شفاف
#1A = 10%  شبه شفاف
#33 = 20%  نصف شفاف
#80 = 50%  نصف ونصف
#FF = 100% غير شفاف
