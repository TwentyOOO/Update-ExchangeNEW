# ExchangeNEW - تطبيق صرافة العملات

## نظرة عامة
تطبيق أندرويد متخصص في تحويل العملات وإدارة عمليات الصرافة بين الدرهم الإماراتي والدولار الأمريكي.

## الإصدار الحالي
**الإصدار 1.0.6** - محسّن ومطور (سبتمبر 2025)

## الميزات الرئيسية
- حاسبة تحويل العملات الفورية
- إدارة محفظة الأرصدة
- تتبع سجلات المعاملات
- واجهة حاسبة عائمة
- دعم أسعار صرف متعددة
- نظام تحديث تلقائي

## التحسينات في الإصدار 1.0.6
تم إصلاح جميع المشاكل البرمجية الحرجة وتحسين استقرار التطبيق بشكل كبير. يتضمن هذا الإصدار إصلاحات لمشاكل القسمة على صفر، تحسين إدارة الذاكرة، وتحسين الأداء العام.
