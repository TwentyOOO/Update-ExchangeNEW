مثال 1: شريط الأزرار بخلفية متدرجة
────────────────────────────────────────────
private LinearLayout createTopButtonsLayout() {
    LinearLayout layout = new LinearLayout(this);
    layout.setOrientation(LinearLayout.HORIZONTAL);
    layout.setLayoutParams(new LinearLayout.LayoutParams(
        ViewGroup.LayoutParams.MATCH_PARENT, 135
    ));
    layout.setPadding(8, 4, 8, 4);

    // ✅ تطبيق الخلفية
    layout.setBackgroundResource(R.drawable.bg_steel_blue_gradient);

    // باقي الكود...
    return layout;
}


مثال 2: الشاشة الرئيسية بخلفية فاخرة
────────────────────────────────────────────
@Override
protected void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);

    // ✅ تطبيق الخلفية على النافذة
    getWindow().setBackgroundDrawableResource(
        R.drawable.bg_steel_blue_premium
    );

    // باقي الكود...
}


مثال 3: تبديل الخلفيات
────────────────────────────────────────────
private void changeBackground(String type) {
    View mainView = findViewById(R.id.main_layout);

    if (type.equals("gradient")) {
        mainView.setBackgroundResource(R.drawable.bg_steel_blue_gradient);
    } else if (type.equals("premium")) {
        mainView.setBackgroundResource(R.drawable.bg_steel_blue_premium);
    }
}

الشفافية المتاحة في colors.xml:

blue_overlay_light    → #0A3498DB  (4%)  خفيف
blue_overlay_medium   → #143498DB  (8%)  متوسط ⭐ الأفضل
blue_overlay_strong   → #1F3498DB  (12%) قوي
blue_overlay_heavy    → #293498DB  (16%) واضح

لتغيير الشفافية، افتح ملف XML الخاص بالخلفية وغيّر:
<solid android:color="@color/blue_overlay_medium"/>

إلى أي خيار آخر.
